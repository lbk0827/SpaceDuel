# Recoil Duel

우주인 둘(플레이어 vs AI)의 레이저 결투. **입력은 클릭 하나** — 총구가 향한 방향으로 레이저가 나가고, 몸은 반동으로 반대로 밀리며 회전한다. 반동이 유일한 이동·조준 수단. 한 방 즉사, 3선승.

설계: [`design.md`](design.md)

## 실행

- **온라인:** https://lbk0827.github.io/SpaceDuel/ — 루트가 standalone 빌드라 단일 파일로 서빙된다(모듈별 캐시 문제 없음). 화면 우하단 `build <시각>` 이 지금 띄운 빌드 시각
- **더블클릭:** `index.html` 또는 동일 내용인 `dist/index.html` (Rapier2D WASM 인라인, 서버·인터넷 불필요, 약 1.5MB)
- **개발:** `python -m http.server 8766` 로 이 폴더를 열고 **`dev.html`** (Rapier 는 CDN, 소스 수정 후 새로고침만)

빌드는 `dev.html` 을 템플릿으로 읽어 `index.html` + `dist/index.html` 을 만든다. **소스만 고치고 빌드를 잊으면 배포에 반영되지 않는다.**

```bash
npm install      # 최초 1회 (esbuild, rapier2d-compat — 빌드 전용)
npm test         # 순수 로직 25개 (geom / laser / firegate / ai)
npm run build    # → dist/index.html
```

## 혼자 하기

시작 화면 → **혼자 하기** → 봇 수를 고른다: **봇 1명(1:1) · 2명 · 3명(4인 난전) · 연습(봇 없음)**.
고른 값은 `botCount` 튠값에 반영되어 다음에도 기본으로 표시된다(✓ 표시). 연습 모드는 상대가 없어 라운드가 끝나지 않는다 — 반동 조작을 익히는 용도.

## 함께 하기 (온라인)

시작 화면에서 **함께 하기** → 방 코드가 생기고 주소가 `?room=XXXX` 로 바뀐다. **초대 링크 복사**로 친구에게 보내면 같은 방으로 들어온다(최대 4인 난전). 방장(먼저 들어온 사람)이 **시작**을 누르면 모두 시작.

- 서버가 없다 — **WebRTC P2P**(Trystero, 공용 릴레이로 만남만 중개). GitHub Pages 그대로 쓸 수 있다
- 만남에 몇 초~수십 초 걸릴 수 있고, 상대가 나타나면 대기실 인원이 자동으로 갱신된다
- **발사는 항상 로컬에서 즉시** 일어난다(몸이 빠르게 돌아 조준이 시간에 민감하므로). 명중 판정은 쏜 쪽이 하고, 방장이 30Hz 로 자세를 뿌려 서로를 맞춘다
- 인원이 늘면 방이 넓어진다: 1~2인 16×9 → 3인 19×10.7 → 4인 22×12.4 (캐릭터가 자동으로 작게 보인다)
- 같은 브라우저 두 탭으로 테스트: `?room=TEST&transport=bc` (BroadcastChannel — 외부 연결 없이 동작)

## 조작·규칙

- 클릭(어디든) = 발사. 총구 방향 = 몸이 향한 방향(점선 가이드). 반동은 총구 위치에 반대 방향 임펄스 → 밀림 + 어깨 지렛대만큼 회전(항상 같은 쪽).
- 색은 슬롯 순서로 **모두에게 동일**하게 보인다: 파랑 · 빨강 · 노랑 · 초록. 내 색은 슬롯 순서에 따라 정해지므로(항상 파랑이 아니다) **내 캐릭터 머리 위에 삼각 표식**이 붙고 HUD 도 `YOU(색이름)` 으로 표시된다. 우주복→빤스→사망 2단계(아래 참고), **마지막 생존자가 라운드 획득**, 전멸은 무득점. 라운드 시작 즉시 발사 가능.
- 탄이 상대에게 맞을 것 같으면 슬로모션.
- 스폰: 방의 네 모서리(2인이면 대각선).

## 목숨과 아이템

**목숨은 2개** — 우주복이 첫 목숨이다. 맞으면 우주복이 깨져 **헬멧+빤스** 상태로 살아남고, 그 상태에서 또 맞으면 죽는다. 피격 순서: 배리어 → 우주복 → 사망.

`itemShipInterval`(기본 12초)마다 **배달 우주선**이 방을 가로지르며 아이템을 떨어뜨린다. 몸으로 닿으면 획득. **아이템과 효과는 라운드마다 초기화**된다.

| 아이템 | 아이콘 | 효과 | 상한 |
|---|---|---|---|
| 배리어 | 파란 방패 | 우주복 바깥의 방어막. 피격을 **1회 막는다**(남은 겹수만큼 몸 주변 호) | 3 |
| 아머 | 흰 우주복 | **빤스 상태면 우주복 복구**. 이미 입고 있으면 변화 없음 | — |
| 웨폰 SPD UP | 노란 레이저 | 레이저 속도 **+35%/개** | 3 |
| 탄창 | 초록 탄창 | 쿨다운 → **에너지(연사) 모드**, 최대 탄약 = 1+개수 | 3 (최대 4발) |

내 상태는 좌하단 칩으로: `우주복 없음!`(빨강) / `BARRIER 2` / `SPD 1` / `MAG 1`.
튠 패널에서 배달선 간격·투하 개수·속도·아이템 수명·속도 증가율을 조절하거나 아이템을 끌 수 있다.
온라인에서는 **방장이 생성·획득을 판정**하고 결과를 알린다(모두가 같은 아이템 상태를 본다).

## 튠 패널 (`` ` `` 키 / `?dev=1`)

중력 · **몸 형태 ball/capsule**(다음 라운드부터) · 반동 임펄스 · 총구 높이(지렛대 = 회전량) · 감쇠/마찰/반발 · 자립 토크(기본 0) · 레이저 속도 · **발사 모드 cooldown/energy** · 쿨다운 · 에너지 최대/충전 · 슬로모 배율/예측 · **AI 허용각/반응지연/재배치 사격** · 선승 · 시작 잠금 · 총구 가이드 표시.
AI 는 명중 예측(지금 쏘면 실제로 맞는가)·회피 사격·똑똑한 재배치를 쓰며 기본값이 강하다 — `AI 반응 지연`을 늘리거나 `AI 회피 예측`을 0 으로 두면 쉬워진다.

패널 하단 버튼: **현재 값을 기본값으로 저장**(이 브라우저에 저장, 재빌드 후에도 유지) · **설정 JSON 복사**(코드 기본값으로 굽고 싶을 때 전달) · **공장 기본값으로**.

콘솔 디버그: `window.__rd` — `state()`, `score()`, `body('player'|'ai')`, `bolts()`, `fire(id)`, `startRound()`.
